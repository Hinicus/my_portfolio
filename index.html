Arduino Robocar

This robot is designed to detect and avoid obstacles. It primarily uses an Ultrasonic Sensor for obstacle detection. Two IR sensors serve as backup to ensure reliable detection if the ultrasonic sensor fails. A servo motor is also used to scan nearby obstacles. The system is powered by an Arduino Uno microcontroller, which processes the sensor data and controls the robot's movement.

Tools used: Arduino IDE, Arduino UNO, IR/Ultrasonic Sensor, DC motors & L298n Motor Driver

Arduino Smart Trashbin

This is a robot that automatically opens its lid when it detects an approaching object, such as a person's hand. Once detected, a buzzer would mimic Doraemon's theme song. It uses an Ultrasonic Sensor to detect the object and and a Servo Motor to open and close the lid. The system is powered by an Arduino Uno microcontroller, which processes the sensor data and controls the servo motor.

Tools used: Arduino IDE, Arduino UNO, Ultrasonic Sensor, Buzzer, & Servo Motor
